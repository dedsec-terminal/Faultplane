### Executive Summary
Microsoft Security Blog investigated a malicious browser extension branded as Claude Code that installs a persistent SSH backdoor on infected systems. The analysis details how the extension masquerades as a legitimate add‑on, the persistence mechanism, detection indicators, and remediation steps. Microsoft provides guidance for identifying and removing the threat.
