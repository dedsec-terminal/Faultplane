### Executive Summary
A local denial‑of‑service vulnerability in Microsoft Windows Aero Theme allows attackers who can run low‑privileged code to trigger a crash by exploiting improper error handling. The Zero Day Initiative assigned CVSS 4.7. Requires local code execution.

This vulnerability allows local attackers to create a denial-of-service condition on affected installations of Microsoft Windows. An attacker must first obtain the ability to execute low-privileged code on the target system in order to exploit this vulnerability. The ZDI has assigned a CVSS rating of 4.7.
