### Executive Summary
Lab research demonstrates that device code phishing—originally targeting OAuth device‑flow clients—can be leveraged against AI coding agents. Using GitHub Copilot CLI as a case study, the study shows how attackers can trick users into authorizing malicious code, exposing credentials and enabling code injection. The findings highlight the need for stricter authentication controls for AI development tools.
