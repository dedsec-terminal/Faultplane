### Executive Summary
A malware campaign leverages SEO‑optimized GitHub repositories that masquerade as legitimate software vendors, including a fake LastPass Authenticator, to distribute a previously undocumented information stealer named Rapuncel. The attackers use these repos to lure users into downloading the malicious package, which harvests credentials and other sensitive data. The operation demonstrates how open‑source platforms can be weaponized for credential theft.
