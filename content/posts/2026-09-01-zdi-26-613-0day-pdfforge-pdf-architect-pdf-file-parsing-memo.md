### Executive Summary
A zero‑day vulnerability (ZDI‑26‑613) in pdfforge PDF Architect allows remote attackers to execute arbitrary code via memory corruption during PDF file parsing. Exploitation requires user interaction, such as opening a malicious file or visiting a malicious page. The vulnerability has a CVSS score of 7.8.
