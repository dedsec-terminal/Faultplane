Claude Opus 5, the latest model from Anthropic, has been launched on Amazon Bedrock and Claude Platform on AWS. This new model improves upon its predecessor, Opus 4.8, with enhanced coding and cybersecurity capabilities. Opus 5 can be accessed by anyone with an AWS account in a supported region, and it allows for more control over high-risk requests, with the option to fall back to Opus 4.8 when necessary.

Opus 5 boasts significant advancements in coding, enabling it to read and write production-quality code like an experienced engineer. It can also run agents that work around obstacles and recover from errors, making it suitable for complex, document-heavy enterprise tasks. Additionally, the model can automate tasks, split large jobs into smaller sub-agents, and produce professional-grade output. Opus 5 also features improved agent automation, allowing it to push back on flawed instructions and manage multi-day projects.

Opus 5 is available on Bedrock in four regions, with more regions listed in the documentation, and on Claude Platform on AWS, covering North America, South America, Europe, and Asia Pacific. The model runs with zero data retention by default and zero operator access, ensuring secure data handling. Engineers can access Opus 5 through the Bedrock console playground or via APIs, with the option to add or remove tools mid-conversation. The customer has control over when Opus 5 falls back to Opus 4.8, providing an added layer of security and flexibility.
