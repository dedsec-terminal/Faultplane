### Executive Summary
An SQL injection flaw in the All‑in‑One WP Migration and Backup plugin for WordPress allows unauthenticated attackers to inject malicious SQL, leading to remote code execution and full site takeover. The vulnerability affects millions of sites, enabling attackers to gain administrative control without credentials.
