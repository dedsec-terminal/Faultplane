### Executive Summary
A Server‑Side Template Injection flaw in Quest Foglight’s renderTemplateString function allows authenticated attackers to execute arbitrary code on affected installations. The vulnerability, identified as ZDI‑26‑866 and assigned CVE‑2026‑92196, carries a CVSS score of 7.2. Exploitation requires valid credentials but can lead to full remote code execution.
