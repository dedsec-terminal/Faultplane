### Executive Summary
A zero‑day vulnerability (CVE‑2026‑50696) in Microsoft Windows allows unauthenticated remote attackers to exploit an integer underflow in the IKEv2 AES‑GCM decryption routine, enabling arbitrary code execution on systems with specific IPsec configurations. The Zero Day Initiative assigned a CVSS score of 8.1.

This vulnerability allows remote attackers to execute arbitrary code on affected installations of Microsoft Windows.
