### Executive Summary
Threat actors are using the npm package 'indexed-btree' to hide malicious code in its normal runtime behavior, bypassing install‑script defenses. The campaign demonstrates how supply‑chain attacks can evade traditional security controls by embedding malware in the package’s runtime rather than during installation. Security teams should monitor runtime activity and review package provenance to detect similar threats.
