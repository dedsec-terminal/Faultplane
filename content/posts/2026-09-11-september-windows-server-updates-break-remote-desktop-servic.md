### Executive Summary
Windows Server 2019, 2022, and 2025 are experiencing Remote Desktop Services (RDS) failures after the September 2026 security updates. Admins report users cannot connect, and in some cases a hard reset is required to restore RDS functionality. The issue appears to be a regression introduced by the latest patches, impacting remote management and remote desktop access for affected servers.
