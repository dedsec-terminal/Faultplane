### Executive Summary
A heap-based buffer overflow in Qualcomm Technologies QCA7005 powerline chips allows physically present attackers to execute arbitrary code without authentication. The Zero Day Initiative rated the flaw CVSS 6.8 and assigned CVE-2026-25293.

**Original Description:**
This vulnerability allows physically present attackers to execute arbitrary code on affected installations of Qualcomm Technologies QCA7005 powerline chips. Authentication is not required to exploit this vulnerability. The ZDI has assigned a CVSS rating of 6.8. The following CVEs are assigned: CVE-2026-25293.
