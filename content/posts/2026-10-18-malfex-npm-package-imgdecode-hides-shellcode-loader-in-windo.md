### Executive Summary
Cybersecurity researchers uncovered a malicious npm package, imgdecode, part of the MALFEX supply‑chain attack campaign. Uploaded on September 30, 2026 by user malfexteste8, the package has 979 downloads and remains available on npm. It embeds a Windows native addon that loads hidden shellcode, enabling remote code execution. The discovery highlights the risk of third‑party npm modules in software supply chains.
