### Executive Summary
Anthropic has acknowledged a flaw in its Claude Dispatch feature that allows any browser extension with control over Claude Dispatch to run code on the user's machine—or even on another machine logged into the same Claude account—without a browser exploit or significant user interaction. The vulnerability, discovered in May, could enable remote command execution across corporate boundaries. Anthropic has declined to patch the issue, leaving organizations exposed.
