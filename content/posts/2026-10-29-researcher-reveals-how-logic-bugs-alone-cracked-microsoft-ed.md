### Executive Summary
A security researcher demonstrated that a chain of logic flaws, without any memory corruption, can allow a malicious web page to escape Microsoft Edge's sandbox and execute code on a Windows system. The exploit, which earned $175,000 at the Pwn2Own Berlin contest in May, was fully disclosed by Orange Tsai of DEVCORE on Oct. 28, five months after the contest. Microsoft patched the Edge bugs the day after the contest.
