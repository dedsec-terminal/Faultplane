Dynatrace has announced significant advancements to its Dynatrace Intelligence platform, which leverages AI agents to automate incident triage and remediation. The platform combines autonomous agents with real-time context and controls, enabling reliable decision-making and automation. This approach addresses the limitations of traditional AI systems, which often lack the context and controls to make informed decisions. With Dynatrace Intelligence, enterprises can automate operations with confidence, reducing manual effort and improving operational outcomes.

The latest release of Dynatrace Intelligence introduces several new features, including autonomous agents for incident triage and remediation, a no-code custom agent creation capability, and an expanded ecosystem of integrations. The Autonomous SRE Agent triggers automatically on newly detected problems, while the Cloud SRE Agent coordinates remediation activities across cloud environments. The Agent Builder enables customers to create custom AI agents without code, extending autonomous operations to unique workflows. Additionally, the platform's integration ecosystem has been expanded to include hyperscalers, enterprise platforms, and developer tools.

The Dynatrace Intelligence platform is designed to provide deterministic, real-time system understanding, grounding every action in environment-specific context. This approach enables enterprises to automate operations with confidence, while maintaining governance and control. According to industry experts, the gap between AI-generated insight and safe, governed execution is a significant concern, and Dynatrace's approach addresses this need. The new features are available to SaaS customers, with some features expected to be available in August. With Dynatrace Intelligence, enterprises can move from understanding problems to resolving them automatically, improving operational efficiency and reliability.
