### Executive Summary
Cybersecurity researchers revealed PEEP, a Chromium‑based post‑exploitation toolkit that masquerades as a bookmarks extension. After gaining administrative or code execution access, its installer injects the extension directly into Chrome/Edge profiles, bypassing Web Store checks and user prompts by forging Chromium’s Secure Preferences. The tool enables host command execution from the compromised browsers.
