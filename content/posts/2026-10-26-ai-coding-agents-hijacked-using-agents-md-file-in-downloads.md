### Executive Summary
Researchers discovered a malicious AGENTS.md markdown file in a user's Downloads folder that lured an AI coding agent into installing a rogue npm package. The file contained deceptive instructions exploiting the agent's prompt injection capabilities, enabling attackers to execute arbitrary code. The incident highlights the vulnerability of AI coding assistants to file-based social engineering.
