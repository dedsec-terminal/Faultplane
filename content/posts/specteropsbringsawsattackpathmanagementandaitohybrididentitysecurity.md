SpecterOps has introduced new capabilities to enhance hybrid identity security by providing a dynamic understanding of how adversaries navigate through environments. The company's BloodHound Enterprise now supports Amazon Web Services (AWS) and Microsoft Entra Agent ID, expanding its attack path management capabilities. This allows defenders to proactively eliminate pathways that can be exploited by attackers before they can be abused.

The new capabilities include the introduction of BloodHound Hunter, a purpose-built AI agent interface that brings adversary intelligence into AI-assisted security workflows. This enables teams to incorporate the power of the attack path graph to address the most critical risks to the business. BloodHound Enterprise identifies and prioritizes attack paths across various platforms, including identity providers, cloud platforms, applications, and repositories, and provides remediation guidance to shut down these pathways before they can be exploited.

The new features allow security teams to add attack path intelligence to AI workflows, map attack paths across hybrid environments, and eliminate attack paths to critical assets within AWS. Additionally, the BloodHound Enterprise extension for Microsoft Entra Agent ID extends attack path management to Microsoft Copilot agents and AI identities, enabling security teams to investigate indirect paths to privileged access. These capabilities enhance the value of BloodHound Scentry, which accelerates identity attack path management maturity by pairing SpecterOps tradecraft expertise with BloodHound Enterprise.
