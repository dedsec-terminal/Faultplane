### Executive Summary
A critical vulnerability chain in the Avada WordPress theme allows unauthenticated attackers to execute arbitrary PHP code on the server via a zero-click exploit. The flaw involves improper input validation in the theme’s file handling, enabling remote code execution without user interaction.
