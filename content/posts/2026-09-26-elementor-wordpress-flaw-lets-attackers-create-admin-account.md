### Executive Summary
A cross‑site request forgery (CSRF) flaw in the Elementor WordPress plugin allows unauthenticated attackers to create new administrator accounts, potentially giving them full site control. The vulnerability can be exploited without prior authentication and is not mitigated by default WordPress security settings.
