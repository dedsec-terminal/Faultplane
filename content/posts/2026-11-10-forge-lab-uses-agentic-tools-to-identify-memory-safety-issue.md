### Executive Summary
Microsoft FORGE Lab researchers discovered memory-safety bugs in Rust's core and standard libraries, including cases where safe Rust code triggers undefined behavior. Using the Hyenas tool (FORGE's MDASH variant), they examined three patterns of misplaced trust in unsafe code, highlighting weaknesses in Rust's safety guarantees.
