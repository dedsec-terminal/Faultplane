### Executive Summary
The PHP development team released security updates addressing 18 vulnerabilities, including critical remote code execution (RCE) flaws that could allow unauthenticated attackers to execute code on vulnerable servers. The patches are available for all supported PHP branches, with versions 8.5.13, 8.4.28, 8.3.37, and 8.2.36 released on November 19.
