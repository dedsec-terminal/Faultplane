### Executive Summary
Attackers exploited a flaw in the optional Collabora Online – Built‑in CODE Server app for Nextcloud, allowing them to plant web shells on affected servers. The vulnerability was reported by three administrators on GitHub, with the first known exploitation occurring on September 10. The web shells enable attackers to execute arbitrary commands with web‑server privileges.
