### Executive Summary
1Password disclosed that a hacker exploited an employee’s corporate GitHub account to inject malicious code, causing the company’s backend services to download customer records. The attacker also copied private repository source code and accessed the CI/CD pipeline. The incident was reported on Nov. 25.
