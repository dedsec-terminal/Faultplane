### Executive Summary

A zero-day vulnerability in the Cacti network monitoring platform has been publicly disclosed, along with a proof-of-concept exploit that lets unauthenticated attackers execute commands on vulnerable servers. The exploit, dubbed " 4HTTP2SHELL " (previously 4HTTP2ROOT), was published on Thanksgiving Day by a cybersecurity researcher known as ek0ms savi0r from the Church of Malware, who demonstrated how the vulnerability can be exploited using just four HTTP requests. Cacti is an open-source network monitoring and graphing tool used to monitor the performance of servers, routers, switches, firewalls, and other network infrastructure.
