### Executive Summary
Cursor reported that a stolen access key from Fireworks AI, exposed after a breach, was used by attackers to copy data and deploy a trojanized version of Anthropic’s Claude Code extension in Cursor’s marketplace. The compromised key allowed unauthorized access to read‑only data, enabling the attackers to inject malicious code into the extension, potentially compromising users who installed it.
