### Executive Summary
Malicious actors exploit a newly patched flaw in PaperCut NG and MF, chaining two vulnerabilities to gain remote code execution without authentication. The attack leverages the application's trusted configuration, allowing arbitrary Java code execution. PaperCut released an emergency fix with additional hardening to mitigate the threat.
