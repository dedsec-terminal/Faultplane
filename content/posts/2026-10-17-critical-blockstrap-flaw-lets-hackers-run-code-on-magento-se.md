### Executive Summary
Researchers warn that a maximum‑severity vulnerability (CVE‑2026‑103849) in Magento’s BlockStrap component could allow attackers to execute arbitrary PHP code on Adobe Commerce servers. The flaw, which affects all Magento 2.x versions, enables remote code execution without authentication, posing a significant risk to e‑commerce sites.
