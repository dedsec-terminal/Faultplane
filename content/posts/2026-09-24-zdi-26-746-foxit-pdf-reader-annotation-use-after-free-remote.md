### Executive Summary
A use‑after‑free flaw in Foxit PDF Reader’s annotation handling allows remote attackers to execute arbitrary code when a user opens a malicious PDF or visits a malicious page. The vulnerability requires user interaction and has a CVSS score of 7.8. It is identified as CVE‑2026‑91818 and was disclosed by the Zero Day Initiative.

**Original Description:**
This vulnerability allows remote attackers to execute arbitrary code on affected installations of Foxit PDF Reader. User interaction is required to exploit this vulnerability in that the target must visit a malicious page or open a malicious file. The ZDI has assigned a CVSS rating of 7.8.
