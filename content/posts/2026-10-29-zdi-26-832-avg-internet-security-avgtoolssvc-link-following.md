### Executive Summary
The Zero Day Initiative (ZDI) has identified a local privilege escalation vulnerability (CVE-2026-6064) in AVG Internet Security's avgToolsSvc component. The flaw allows an attacker with low‑privileged code execution to elevate privileges via link following. The CVSS score is 7.3.

**Original Description:**
This vulnerability allows local attackers to escalate privileges on affected installations of AVG Internet Security. An attacker must first obtain the ability to execute low-privileged code on the target system in order to exploit this vulnerability. The ZDI has assigned a CVSS rating of 7.3. The following CVEs are assigned: CVE-2026-6064.
