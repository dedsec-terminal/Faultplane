### Executive Summary
A remote code execution vulnerability (CVE-2026-20350) in Cisco ThousandEyes Virtual Appliance allows authenticated attackers to inject commands via the DHCP client, enabling arbitrary code execution. The flaw carries a CVSS score of 7.2 and was identified by Zero Day Initiative.
