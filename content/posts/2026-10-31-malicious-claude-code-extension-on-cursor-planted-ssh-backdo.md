### Executive Summary
A malicious variant of Anthropic’s Claude Code VS Code extension was briefly available in Cursor’s marketplace on Oct 29, exposing up to 5,000 developers. The malware installs persistent SSH backdoors, enabling remote access. The distribution lasted about 11 hours before removal.
