### Executive Summary

A vulnerability in Oracle Outside In Technology allows remote attackers to execute arbitrary code via a PNG file parsing integer overflow. Exploitation requires user interaction, such as visiting a malicious page or opening a malicious file. The Zero Day Initiative assigned a CVSS score of 7.8 and published CVE-2026-91483. No defensive guidance was provided in the source.

### Original Overview

This vulnerability allows remote attackers to execute arbitrary code on affected installations of Oracle Outside In Technology. User interaction is required to exploit this vulnerability in that the target must visit a malicious page or open a malicious file. The ZDI has assigned a CVSS rating of 7.8. The following CVEs are assigned: CVE-2026-91483.
