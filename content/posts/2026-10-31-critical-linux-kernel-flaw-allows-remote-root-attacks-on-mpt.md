### Executive Summary
Security researchers at Anthropic discovered a critical Linux kernel vulnerability that lets unauthenticated attackers remotely execute commands as root on servers running Multipath TCP (MPTCP) listeners. The flaw, affecting kernel versions X‑Y, can be triggered via crafted network packets, enabling full system compromise without authentication. Anthropic released an exploit and urged affected organizations to patch immediately.
