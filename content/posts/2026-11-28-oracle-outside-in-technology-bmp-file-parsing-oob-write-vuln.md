### Executive Summary

A vulnerability in Oracle Outside In Technology’s BMP file parsing allows remote attackers to execute arbitrary code on affected installations. The flaw is an out‑of‑bounds write that requires interaction with the library, though specific attack vectors may differ by implementation. Zero Day Initiative has assigned CVE‑2026‑91457 and a CVSS score of 7.8.

### Original Overview

This vulnerability allows remote attackers to execute arbitrary code on affected installations of Oracle Outside In Technology. Interaction with this library is required to exploit this vulnerability but attack vectors may vary depending on the implementation. The ZDI has assigned a CVSS rating of 7.8. The following CVEs are assigned: CVE-2026-91457.
