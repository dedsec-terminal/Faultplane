### Executive Summary
Apiiro research uncovered 2,539 real secrets in 1,994 public GitHub repositories, including database passwords, cloud keys, API tokens, and SSH root logins. Notable leaks include a vendor’s admin‑level cloud key, a production Azure PostgreSQL password, a Square production token, and a medical‑records database owner password. The findings span 63 organizations, highlighting widespread exposure of sensitive credentials in public code.
