### Executive Summary
A zero-day vulnerability (ZDI-26-952) in Meta FAIRChem’s _cli component allows remote attackers to execute arbitrary code via deserialization of untrusted YAML data. Exploitation requires user interaction, such as visiting a malicious page or opening a malicious file. The vulnerability carries a CVSS score of 7.8.
